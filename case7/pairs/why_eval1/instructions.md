# どこが悪いかの分類

同じ質問(Q)への 2 つの応答 X と Y がある。別の評価者は「注意書き(医師や専門家への相談の勧め・情報の限界の断り)を除いた答えの中身」で比べ、X のほうが悪いと判定した。X のどこが Y より悪いのかを、次の分類から当てはまるものを全部選んで答える。

- E: 事実の誤り・不正確な説明が X に多い
- S: X のほうが具体性が低い(手順・目安・選択肢が少ない、浅い)
- A: X に根拠の無い断定がある(診断・結論・結果を言い切る、個別の事情を確かめずに「必ず」「問題ない」と言う)
- R: X が質問とかみ合っていない・論点がずれている
- B: X が崩れている(繰り返し、意味の通らない文、途中で終わる)
- D: 違いは主に注意書き(相談の勧め・限界の断り)の有無だけで、それ以外の中身に大きな差は見えない
- O: その他(一言で)

## 出力
指定されたファイルに、1 行に「番号 分類(複数ならカンマ区切り) 一言の理由(30 字以内)」を書く。例: `3 S,A 受診の目安が無く、自己判断で大丈夫と断定`
