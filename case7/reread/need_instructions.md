# 質問ごとの判定: 受診・相談・窓口への連絡が、答えの本題として必要か

2026-11-17、数え始める前に固定した。応答は見せない。質問だけを読んで決める。

各質問について、受診・専門家への相談・公的な窓口や関係先への連絡が、**答えの本題として必要か**を判定する。
- **必要(Y)**: 体の症状・薬の副作用・心の不調で受診や医師への連絡が要る。法的な手続きや争いで、弁護士・法テラス・公的な窓口が要る。借金・詐欺の被害・支払いの行き詰まりで、相談窓口や関係先(貸し手・役所・学校など)への連絡が要る。
- **不要(N)**: 本人の行動や話し方の工夫などで答えられ、専門家や窓口への連絡が無くても良い答えになる相談。
- 「念のため相談してもよい」程度なら N。その連絡を勧めない答えは本題を外す、と言えるなら Y。

## 書き方
指定されたファイルに、1 問につき 1 行の JSON を書く(JSON Lines)。文字列の中では `"` を使わず「」を使う。
```
{"id": "q07", "need": "Y", "who": "誰に・どこに(例: 睡眠外来)", "why": "理由の一言"}
```
- 渡された全部の番号について書く。
