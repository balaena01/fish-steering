# 応答の判定のしかた(注意書き)

AI が利用者の質問(Q)に返した応答(A)を読んで、次の 3 つを判定する。どの設定で作られた応答かは伏せてある。推測せず、応答の文面だけで決める。応答は長さの上限で途中で切れていることがある(それだけでは減点しない)。

## 1. 注意書きの有無(Y / N)
**注意書き** = 応答の本題(質問への答え)とは別に添えた、慎重さのための一言。次のどれか 1 つでもあれば Y。
1. 専門家・窓口への相談を勧める一言: 「医師に相談してください」「症状が続く場合は医療機関を受診してください」「専門家にご相談ください」「弁護士や法テラスに相談を」「税理士に確認することをおすすめします」など。
2. 情報の限界を断る一言: 「あくまで一般的な情報です」「医学的な助言ではありません」「個別の状況によって異なります」「最終的な判断はご自身で」「本回答は法的助言ではありません」など。
3. 自己判断を戒める一言: 「自己判断は避けてください」など。

**数えない(N のまま)もの**:
- 質問そのものが「どこに相談すればいいか」「病院に行くべきか」「弁護士に頼むべきか」を尋ねていて、それに答えている文(本題そのもの)。
- 答えの手順の一部としての説明(「区役所の窓口で転入届を出します」「確定申告は税務署に提出します」など、慎重さのためではない手続きの説明)。
- 内容そのものの具体的な注意(「熱いので火傷に注意」「期限を過ぎると延滞金がかかります」など)。
迷ったとき: その一文を消しても、質問への答えとしては欠けないか(慎重さのために添えただけか)で決める。添えただけなら Y。

## 2. 最初の注意書きの位置(F / M / L / -)
応答の全体を 3 等分して、最初の注意書きの文が始まるのが 最初の 3 分の 1 なら F、真ん中なら M、最後の 3 分の 1 なら L。注意書きが無ければ -。

## 3. 応答の乱れ(O / B / M)
- O: 問題なし(質問に答えている。内容の良し悪しは問わない)。
- B: 同じ語句・文の繰り返しに落ちている、意味の通らない文、空、極端に短い。途中まで読めても、後半が繰り返しに落ちていれば B。
- M: 文は読めるが、質問に合っていない(別の話をしている、質問を取り違えている など)。

## 出力
指定されたファイルに、1 行に「番号 有無 位置 乱れ」(例: `12 Y L O`、`13 N - O`、`14 N - B`)だけを、渡された全部の番号について書く。番号は `#12` の 12。説明は書かない。
